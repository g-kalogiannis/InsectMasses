## A repository for storing the code and data used to create an insect size and mass data set.
* **Author:** Georgios Kalogiannis
* **Email:** georgios.kalogiannis@uzh.ch

## Structure
* There are three directories included in this repository: ```code/```, ```data/```, and ```results/```.
* Users should set ```code/``` as their working directory, as output files are created relative to this. 
* The code/ directory contains:
    * mass.Rmd – the primary R Markdown workflow used to assemble, standardise, analyse, and visualise insect body size and mass data.
    * mass.R – a script version of the workflow for running the data assembly and processing pipeline without the R Markdown framework.
    * mass_conversions.R – functions and reference data used for body size–mass estimation, including taxon-specific allometric equations and wet-to-dry mass conversions.
* Files within data/ are organised according to their source or content.
The results/ directory contains processed datasets, figures, tables, and other outputs generated by the analysis pipeline.

## Dataset
* The database compiles published measurements of insect body size and body mass from a wide range of online and literature sources.
* Measurements are standardised to common units and converted where appropriate to facilitate comparison across taxa.
* Body size records can be converted to mass using taxon-specific allometric relationships, while dry and live mass measurements are harmonised using published wet–dry conversion factors.
* The current dataset contains approximately 20,000 records representing over 7,600 insect species across 19 orders.
